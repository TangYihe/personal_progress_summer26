- **🔎 Code check: per-joint leg locking IS available — the 07-24 note ("no per-joint lock config")
  is wrong on this tree.** Verified 2026-08-03:
  - `profile.torso ∈ {hold, ik}` only ([launcher.py:129](../../../we-teleop/src/teleop/runtime/launcher.py#L129)),
    and `torso: ik` adds **all 6** leg joints to the IK active set
    ([ik_process.py:59-63](../../../we-teleop/src/teleop/runtime/ik_process.py#L59-L63)) — so the
    *profile* switch really is all-or-nothing.
  - **But `config/embodiments.yaml:141` `ik.frozen_joints` subtracts from that set** —
    `optimized_joints = active_joints - frozen`
    ([solver.py:249](../../../we-teleop/src/teleop/control/kinematics/solver.py#L249)). Frozen joints
    are excluded from IK and held at the solve seed. **That is exactly the "lock a joint" idea, and
    it is pure config.** Names must be exact (`Gento Luna_Leg_J1_Joint`); unknown names raise at
    load; you cannot freeze every active joint.
  - ⚠️ **It is global to the embodiment, not per-profile** — a freeze applies to every profile
    including deploy/replay. Re-check the autonomous path after freezing anything.
- **🦵 Which joint to lock — the standing pose answers it.** `config/embodiments.yaml:46-47`
  `start_degrees.torso: [0.0, 60.0, -70.0, 10.0, 0.0, 0.0]`. **J2 (+60°) + J3 (−70°) + J4 (+10°)
  sum to zero** = the sagittal hip/knee/ankle chain that keeps the upper body vertical.
  **J1, J5, J6 sit at 0** = the out-of-plane (yaw/roll) DOFs, which contribute nothing to a
  straight-ahead squat. → **freezing J1/J5/J6 is kinematically free** and removes 3 redundant DOF the
  IK can wiggle; freeze J4 only if shake persists, since that one costs real squat range.
  ⚠️ Inferred from the start values + the sum-to-zero pattern, **not** from URDF axes — confirm by
  jogging each joint in sim (10 min, no robot).
- **Other anti-shake levers found** (full ladder in the checklist): torso velocity/accel caps
  (`config/runtime.yaml:45-46`, currently `1.0` rad/s and `10.0` rad/s² — the *reset* ramp already
  runs a visibly smooth `0.2`/`0.4`, a proven-calm target to interpolate toward) · per-joint
  `smoothness_joint_weights.torso` (`[3.0]×6`, arms are `1.0`) · per-joint `rest_joint_weights.torso`
  (`[12.0]×6`). Upstream already stiffened the legs relative to the arms, which suggests they hit
  this too.
